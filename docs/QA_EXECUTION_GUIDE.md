## 1️⃣ 기능 테스트

### 1.1 회원가입 / 로그인

**A. Google 로그인**
1. 브라우저 시크릿 모드 열기
2. https://jobizic.com 접속
3. "Google로 시작하기" 클릭
4. Google 계정 선택
5. ✅ 대시보드로 자동 리다이렉트 확인
6. ✅ 상단에 이름/이메일 표시 확인

**B. 이메일 로그인** (구현된 경우)
1. "이메일로 시작하기" 클릭
2. 이메일 입력 → 인증 메일 확인
3. ✅ 로그인 성공 확인

**C. 로그아웃**
1. 상단 프로필 클릭 → "로그아웃"
2. ✅ 메인 페이지로 리다이렉트 확인

**D. 중복 가입 방지**
1. 동일 이메일로 재가입 시도
2. ✅ 기존 계정 자동 로그인 확인

---

### 1.2 이력서 분석

**A. 파일 업로드**
1. 대시보드 → "이력서 분석" 클릭
2. PDF 파일 업로드 (테스트용: sample_resume.pdf)
3. ✅ 파일명 표시 확인
4. ✅ "분석 시작" 버튼 활성화 확인

**테스트 파일 준비:**
- PDF: 정상 이력서 (2MB 이하)
- PDF: 대용량 파일 (10MB - 오류 메시지 확인)
- TXT: 지원하지 않는 포맷 (오류 메시지 확인)

**B. 분석 결과 표시**
1. "분석 시작" 클릭
2. ✅ 로딩 스피너 표시
3. ✅ 30초 이내 결과 표시
4. ✅ 총점 (0-100) 표시
5. ✅ 세부 점수 (기술역량, 경험연차, 도메인핏, 컬처핏) 표시
6. ✅ 강점/약점 텍스트 표시

**C. FREE 플랜 3회 제한**
1. 연속 3회 분석 수행
2. ✅ 분석 횟수 표시 (1/3, 2/3, 3/3)
3. 4회차 시도
4. ✅ "플랜 업그레이드 필요" 메시지 표시
5. ✅ PRO 플랜 페이지 링크

**D. 분석 결과 저장**
1. 분석 완료 후 "저장" 클릭
2. 대시보드 → "분석 히스토리" 이동
3. ✅ 저장된 분석 결과 표시 확인

---

### 1.3 플랜 / 결제

**A. FREE → PRO 결제**
1. "플랜" 페이지 이동
2. PRO 플랜 "선택하기" 클릭
3. PortOne 결제 팝업 확인
4. **테스트 카드 번호** 사용:
   ```
   카드번호: 4000 0000 0000 0002
   유효기간: 12/34
   CVC: 123
   ```
5. ✅ 결제 완료 메시지
6. ✅ 플랜 변경 확인 (FREE → PRO)
7. ✅ 무제한 분석 가능 확인

**B. 결제 실패 시나리오**
1. 잘못된 카드 번호 입력
2. ✅ "결제 실패" 오류 메시지 표시
3. ✅ 플랜 변경 없음 확인

### 3.2 부하 테스트

**k6 부하 테스트 스크립트** (설치: `npm install -g k6`)

```javascript
// load-test.js
import http from 'k6/http';
import { sleep } from 'k6';

export let options = {
  stages: [
    { duration: '1m', target: 10 },  // 10명으로 증가
    { duration: '3m', target: 50 },  // 50명으로 증가
    { duration: '1m', target: 100 }, // 100명으로 증가
    { duration: '2m', target: 0 },   // 0명으로 감소
  ],
};

export default function () {
  http.get('https://jobizic.com');
  sleep(1);
}
```

**실행:**
```bash
k6 run load-test.js
```

**목표:**
- ✅ 100 동시 사용자 처리 가능
- ✅ 응답 시간 < 3초
- ✅ 에러율 < 1%
