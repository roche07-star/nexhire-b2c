## 📍 Google Ads 설정

### 캠페인 구조
```
캠페인 1: 검색 - 고의도 (150만원)
  ├─ 광고그룹 1: 이력서 분석 (50만원)
  ├─ 광고그룹 2: AI 이력서 첨삭 (50만원)
  └─ 광고그룹 3: 자기소개서 분석 (50만원)

캠페인 2: 검색 - 중의도 (90만원)
  ├─ 광고그룹 4: 취업/이직 준비 (60만원)
  └─ 광고그룹 5: 이력서 작성법 (30만원)

캠페인 3: 브랜드 (60만원)
  └─ 광고그룹 6: Jobizic 브랜드 (60만원)
```

### 타겟팅 설정
- **지역**: 전국 (서울/경기 우선 입찰 +20%)
- **연령**: 20-40세
- **디바이스**: 모바일 우선 (+15%)
- **요일/시간**: 
  - 평일 18:00-23:00 (퇴근 후) +30%
  - 주말 14:00-20:00 +20%

### 확장 기능
- ✅ 사이트링크: 무료 체험, 요금제, 후기
- ✅ 콜아웃: "무료 3회", "1분 분석", "Claude AI"
- ✅ 구조화된 스니펫: 기능 (이력서 분석, 강점 파악, 개선 제안)
