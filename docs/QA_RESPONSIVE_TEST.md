## 🎨 공통 체크 항목

### 레이아웃
- [ ] 가로 스크롤 없음 (전체 페이지)
- [ ] 터치 타겟 최소 44x44px
- [ ] 여백 적절 (모바일 16-20px)
- [ ] 텍스트 최소 16px (모바일)

### 타이포그래피
- [ ] clamp() 또는 미디어 쿼리로 반응형 폰트

- [ ] 가독성 (line-height 1.5+)

- [ ] 로딩 상태
- [ ] aspect-ratio 유지

