## ✅ 5. 사용자 시나리오 테스트

### 시나리오 1: 신규 가입 → 무료 체험
1. Google로 가입
2. 이력서 업로드 (PDF)
3. 분석 결과 확인
4. 만족 → 대시보드 저장
5. 2회 더 분석 (총 3회)
6. 4회차 시도 → 플랜 페이지 유도

### 시나리오 2: 무료 체험 → PRO 결제
1. 무료 3회 소진
2. 플랜 페이지 이동
3. PRO 플랜 선택
4. 결제 진행
5. 결제 완료 → 무제한 분석 가능 확인

### 시나리오 3: 이탈 케이스
1. 신규 가입
2. 이력서 업로드
3. 분석 결과 불만족
4. 이탈 (피드백 수집)
